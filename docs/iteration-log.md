# 迭代紀錄：第一版的路徑 B 通過了檢定，而它是壞的

熱線的分析腳本迭代過二十幾個版本：`W1` → `W1b` → … → `W1g`、`W2` → `W2b` → `W2c`、
`W2pre` → `W2pre_b` → `W2pre_c`、`W3` → `W3b` → `W3c`。

repo 只放最終版。**但其中有一段值得單獨寫出來，因為它是這整個專案最重要的一次失敗。**

---

## 發生了什麼

第一版的路徑 B（`W2_process.py`）要在放電段解 Bernardi 產熱模型，
擬合出熱容 `m·Cp` 與散熱能力 `h·A` 兩個自由參數，再由 `τ = m·Cp / h·A` 得到時間常數。

它跑完了，而且**答案漂亮到不合理**：

| 檢查 | 第一版路徑 B | 對照 |
|---|---|---|
| 相容性檢定 | **未拒絕（通過）** | 落差 41.00 s，容差半寬 200.07 s |
| `τ_B` | **800.00 s** | 路徑 A：841 s |
| `h·A` | **0.0500 W/K** | 路徑 A：0.0499 W/K |
| `m·Cp` | **40.00 J/K** | 文獻典型值：42 J/K |

三個物理量全部對得上。散熱能力甚至**對到小數點第三位**。

如果就這樣交出去，這會是一個「兩條獨立路徑互相驗證成功」的故事。

---

## 那三個數字是初值

`W2_process.py` L220：

```python
res = least_squares(residuals, [40, 0.05], bounds=([5, 0.005], [150, 0.5]))
#                               ↑
#                               初值：m·Cp = 40 J/K, h·A = 0.05 W/K
#                               也就是 τ = 40 / 0.05 = 800 s
```

166 個循環擬合完之後，`w2_fit_by_cycle.csv` 裡是這樣：

```
mCp_JK    中位數 40.0              (最小值 39.544)
hA_WK     中位數 0.0500000009      (最小值 0.0499917)
tau_B_s   中位數 799.99999
```

**優化器一步都沒有走。它把初值原封不動交了回來。**

而那組初值恰好落在容差窗的正中央——所以它「通過」了相容性檢定。

---

## 抓到它的不是眼睛

曲線是貼合的、殘差是小的、三個物理量是對的。**用看的看不出來。**

抓到它的是一項事前登記的檢查：**換一組初值重跑，看答案會不會跑掉。**

`w2_verdict.md` 第 6 條：

```
6. 多解性最大差值 (A,B初值): 411.53 s
   標注: 多解性顯著 (中位數 > 1 s)。
```

用 `[20, 0.02]`（τ = 1000 s）當初值重跑，答案跑掉 **411.53 秒**。

一個真正被資料鎖住的參數，不會因為你從哪裡開始找而改變 411 秒。
**這個模型在這批資料上，根本沒有唯一解。**

---

## 修好之後

`W2b_process.py` 改用固定步長 RK4 積分（消除自適應步長雜訊，讓 Jacobian 穩定），
並加上多重起點的收斂檢查。

| | 第一版 `W2` | 修好後 `W2b` |
|---|---|---|
| 換初值最大差 | **411.53 s** | **0.02 s** |
| `τ_B` | 800.00 s | **2088.35 s** |
| 與 `τ_A` 的落差 | 41.00 s | **1247.35 s** |
| 容差半寬 | 200.07 s | 186.31 s |
| **判定** | 未拒絕相容性 | **拒絕相容性（FAIL）** |
| `h·A` | 0.0500 W/K | **0.0380 W/K** |
| `m·Cp` | 40.00 J/K | **79.85 J/K** |

同一批資料、同一個模型、同一條物理路徑。**只是這次優化器真的在找解。**

答案從「兩條路徑一致」變成「兩條路徑差了 1247 秒，是容差的 6.7 倍」。

---

## 為什麼把這一段留著

因為工程上最危險的情況不是程式報錯。

**是程式跑完了、數學收斂了、殘差很小、三個物理量都對得上——而它是錯的。**

那個第一版沒有任何一項外顯症狀。它唯一的破綻，是一項在看到結果之前就決定要做的檢查。

> 這也是報告第 4 頁的來源：**曲線疊得上是可以調出來的。**
> 所以後來改成設計兩條假設量不同的獨立路徑，讓它們去撞，而不是去疊。
